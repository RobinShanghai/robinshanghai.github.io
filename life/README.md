# 人生的变量：V2.0 核心系统预览

静态网页，无服务器、无付费 API。当前沿用 Ethan 的12次选择测试章，新增多分支 Save / Load。新人物与历史剧情接入进度见 ../PROJECT_PROGRESS.md。

打开 index.html（建议 HTTP 静态服务器）。点击“走进另一种人生”；选择前自动创建检查点。Save / Load 可手动保存，读取检查点会新建分支；“继续此分支”接续原分支。相同起点重玩保留原路线。设置可导出全部分支，导入始终追加。旧 v2.2 单存档格式兼容。

测试：`node --test tests/life-saves.test.cjs`（仓库根目录）。

角色与个人剧情虚构；当前测试角色于2026年18岁开局，此后的事件不是历史事实。最终产品将接入1950—2000年出生的人物。肖像为已有 AI 生成素材。
