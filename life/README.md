# 人生的变量 · V2.0 特色人物青年篇

8位可选人物：美国美男、中国实业家千金、英国音乐天才、巴西新演员、日本科学天才、韩国财阀继承人、德国出版家继承人、法国运动新星。出生1955—1990年，18岁开局，每人12次重大选择（4—5个有效选项）。这是青年阶段，非完整人生。

人物选择、国家/特质联合筛选、筛选范围随机抽取；属性含外貌、智力、家庭财富、社会地位、家庭人脉、艺术、运动、社交、健康与性格。具名导师和朋友、独立家庭及目标。人物专属开局与合作场景，公共事件依路线、关系和标记变化。财富/天赋开启额外机会；富裕人物不被强制惩罚。

技术：原 life/engine.js 和 saves.js 保持不变。characters.js 定义角色；character-engine.js 增量包装旧引擎。旧 version:1 存档继续使用旧逻辑；新 version:2 人物状态保存全部特质/关系/标记/RNG。Save/Load、多分支、旧存档导入、完整导出沿用现有实现。

本地测试：`node --test tests/*.test.cjs`。不需要安装依赖；GitHub Pages 静态网页。人生进度只存当前浏览器，换设备前请导出。

历史出处随人物数据 source 链接展示：美联储历史、世界银行、巴西央行、日本央行、IMF、德国联邦政府、澳大利亚储备银行。历史事实与虚构角色/经济幅度分开。经济按开局币值简化，不进行真实通胀、汇率或投资收益预测。肖像复用原有 AI 生成素材。
